# 数据字段字典（数据 Agent 交付 · 2026-09-23）

单位约定：距离 **km**、时间 **min**（相对当日 00:00）、重量 **kg**、速度 **km/h**。
坐标：`lon/lat` 为 GCJ-02；`*_wgs` 为 WGS-84；`plane_x/y_km` 为平面投影
（中心 119.30°E/26.08°N，x=(lon−119.30)×100.0，y=(lat−26.08)×110.94，单位 km）。
随机数据 seed=2025。

## data/geo/

| 文件 | 字段 | 说明 |
|------|------|------|
| fz_road_network.graphml | 节点 id, lon, lat；边 km, hw, speed | A1 福州骑行路网（最大弱连通分量，168691 节点 / 306701 边）。`hw`=OSM highway 等级，`speed`=该等级基准速度 km/h |

## data/matrices/（A2，CSV UTF-8-BOM）

| 字段 | 说明 |
|------|------|
| src_id / src_name / src_lon / src_lat | 源点 = **fz_orders_1550.csv 的唯一订单节点全集**（pickup 1503 / delivery 1460），保证订单节点 ⊆ 矩阵节点、覆盖率 100%（2026-09-23 核验后修正：此前随机采样 500 导致 96% 订单查不到路网距离） |
| pad_id / pad_name / pad_lon / pad_lat | 目标停机坪（C2 正式候选前 15，剔除禁飞判定） |
| road_km | 路网最短骑行距离，**-1 = 不可达**（路网孤立分量） |
| ride_min | road_km ÷ 25 km/h × 60（基准速度，路况折扣另乘 A3 表） |

规模：pickup 22545 行 / delivery 21900 行，合计 44445 行。

### 交接点矩阵（`fz_matrix_*_handoff.csv`，9 主模型节点版）

| 字段 | 说明 |
|------|------|
| src_id / src_name / src_lon / src_lat | 源点 = fz_orders_1550.csv 唯一订单节点全集（pickup 1503 / delivery 1460），GCJ-02 |
| pad_id / pad_name / pad_lon / pad_lat | 坪 = fz_handoff_nodes_master.csv 全部 9 个主模型节点（FZ-TP-001~019），**此处坐标为 WGS84→GCJ-02 转换后口径**（原始清单是 WGS84；福州偏移数百米，混用会导致查表系统性偏差） |
| road_km / ride_min | 同上口径，ride_min = km / 25km/h × 60 |

规模：pickup 13527 行（1503×9）/ delivery 13140 行（1460×9），与旧 15 坪矩阵**并存不覆盖**；实验侧切换文件名即用。
⚠️ 路网覆盖边界口径（两版矩阵相同）：路网 bbox 外或远离路网的 POI 会被硬吸附到最近路网节点（约 18.6% src 吸附距离 >2km），其 road_km 为「吸附节点间路网距离」，可能小于 POI 间直线距离；不可达仍为 -1 显式标记（约 1.5%）。

## data/params/（A3/C1/C2/C3/C4/D2/D3）

**fz_traffic_factor.csv（A3 时段路况折扣）**：时段、起止、速度折扣（实际/基准，0.7~1.0）、说明。
**fz_rider_speed.csv（C4）**：骑手速度 N(25,4) km/h，截断 [12,40]，按骑手 ID 抽样、订单内不变。
**fz_weather_factor.csv（D2）**：天气、骑手速度折扣、无人机速度折扣（大雨/大风/台风=0 即禁飞）、说明。
**fz_drone_model.csv（C1）**：DJI FlyCart 30 与顺丰丰翼方舟40 公开规格（载荷/巡航/航程/续航/换电/抗风/防护）。
**fz_pads_candidates.csv（C2，60 个 ≥50 达标）**：
| 字段 | 说明 |
|------|------|
| pad_id / 名称 / 业态 / 区县 | 源自 relay 池（停车场/公园广场/轨道站点/体育场馆） |
| lon_gcj02 / lat_gcj02 / plane_x_km / plane_y_km | 三坐标系 |
| 容量等级 | 大/中/小（业态粗分） |
| 起降可行 | 1=地面起降可行（停车场/公园/场馆），0=需改造 |
| 距市中心_km / 综合得分 | 得分=0.5 业态+0.3 区位环带+0.2 楼顶加分 |
**fz_nofly_zones.csv（C3，26 区）**：zone_id、名称、等级（禁飞/限飞）、顶点数、质心、polygon 概要。
**fz_pads_nofly_dist.csv**：pad_id、名称、最近禁飞区、距离_km、距最近机场_km、空域判定。
判定口径：**跑道沿线 2km 缓冲内=禁飞，2-6km=限飞，>6km=可飞**（净空区口径，
非机场基地区域半径判定——义序机场在市区，基地区域口径会全城禁飞，实测 0/60 假结果）。
分布：可飞 17 / 限飞 30 / 禁飞 13。

## data/orders_expanded/（B1-B4/D1/D3，CSV UTF-8-BOM）

**fz_orders_1550.csv（B1，1552 单 ≥1500 达标，seed=2025）**：
| 字段 | 说明 |
|------|------|
| order_id | X00001 起连续编号 |
| pickup_id/name/lon/lat | 取货点（fz_dataset pickup 池，GCJ-02） |
| delivery_id/name/lon/lat | 送达点 |
| ready_min / due_min | 生成时刻 / 承诺时刻（min） |
| tw_tier | B2 三档：加急30-45min(30%) / 标准60min(60%) / 宽松90-120min(10%) |
| time_slot | 时段（早/午/晚高峰…，沿用 build_dataset 口径） |
| straight_km | 取-送直线距离 |
| weight_kg | 0.3~2.4 均匀 |
| uav_suitable | 1=直线≥3km 且 80% 概率适航（建模近似） |

**fz_arrival_rate.csv（B3）**：时段、起止、权重、lambda_per_min（单/min）。
**fz_distance_bands.csv（B4）**：0-3/3-8/8-15/>15km 订单数与占比
（实测 237/594/504/217 = 15.3%/38.3%/32.5%/14.0%）。
**fz_poisson_arrival.csv（D1）**：32 个 30min 桶的 λ（单/min）+ 期望单数；
尾部 SPIKE 行=批量到达事件（午/晚高峰整点 λ×2 持续 10min）。
**fz_arrival_sim_sample.csv（D1/D3 仿真样例，seed=2025）**：t_min、order_ref、event(NEW/CANCEL)；
1620 事件（NEW 1571 / CANCEL 49，中档 3.5% 取消率）。
**fz_cancellation.csv（D3）**：取消率三档 2%/3.5%/5%，改派占比 60%，
取消时点=生成后 5-45min 均匀。
